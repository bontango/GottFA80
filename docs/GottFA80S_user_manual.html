Important remark

By using GottFA80S it is possible to damage your pinball machine. As this is a private project with NO commercial interest the author accepts no liability for any damage that may arise by using GottFA80S!

1. Introduction

GottFA80S replaces the MPU and the soundboard of your Gottlieb System80, System80A or System80B game. The integrated soundboard emulates the Gottlieb soundboards MA-55, MA-216 (with speech), MA-309 and MA-490 (chapter 6).

GottFA80S is a 100% hobby project. This makes the solution cheap; depending on where you buy your components it is possible to build your Gottlieb replacement MPU for less than 50 €.

What do you need?

  • Basic soldering skills
  • Possibility to read/write micro SD cards
  • A PC with an USB port and an USB Blaster in order to be able to program the FPGA
  • Gottlieb rom images (not included due to copyright limitation)

1.1. New in software x.x5

Software x.x5 is the first version built from the common GottFA80 source tree, which since November 2026 holds GottFA80S together with GottFA80_PLuS and GottFA80 (SMD). GottFA80S now runs the same program as GottFA80_PLuS.

  • New version numbers per board (chapter 8.4): the old numbers 50x/51x/61x were the same as those of GottFA80_PLuS.
  • Text boot display on System80B games (chapter 5.3).
  • Clearer boot display. Player 2 shows the game number with three digits, player 4 the setting of the option and soundboard switches (chapter 5.2).
  • SD card diagnosis by blink codes of the 'SD card' LED (chapter 5.1).
  • New variant for HW 1.1 with a small modification: it reads the game roms from the FPGA flash if no SD card answers (chapter 10).

Test status: x.x5 has been tested on the modified HW 1.1 (545). The other boards have not been tested with x.x5 yet; chapter 8.4 lists the last released file for each board.

2. Quickstart

  1. Download the latest versions of the SD card image and the FPGA program from lisy.dev - the FPGA program for your board, see chapter 8.4
  2. Write the image to a SD card (chapter 7)
  3. Add Gottlieb roms (chapter 9)
  4. Program the FPGA (chapter 8)
  5. Configure switch 'game select' according to your pinball (Appendix A)
  6. Set option Dip2 'init nvram' to ON for the first start
  7. Replace your original System80 MPU and soundboard with GottFA80S
  8. Switch the game ON - then switch it off, set option Dip2 back to OFF and switch it on again
  9. Enjoy

For all my 'FA' boards you will find a user manual on the 'product page'. However all these boards have in common that you need to:

  1. select a SD card which works with my 'FA' boards
  2. put the image to the SD card
  3. buy or build an USB Blaster
  4. program the FPGA

Information about my different DIY FPGA boards you can find here.

3. Installation

GottFA80S boards have the same connectors and the same mounting holes as the original Gottlieb System80 MPUs, so replacing the board can be done in seconds.

The sound comes from the integrated soundboard: connect the 'soundboard adapter' (bottom left on the picture) to the soundboard connector of your machine. The two potentiometers 'Speech Vol.' and 'Sound Vol.' set the volume of speech and sound.

4. Dip Switch Settings

The four DIP banks on the left (S1...S8, S9...S16, S17...S24, S25...S32) are the same as on the original MPU. The three banks on the right are for game selection, the GottFA80S options and the soundboard options.

A DIP switch is 'ON' when it is pushed to the 'ON' side of the bank. The numbers shown on the boot display count the switches that are ON (chapter 5.2).

4.1. Game select

Here you select which game GottFA80S runs. The six switches form the game number in binary: Dip1 = 1, Dip2 = 2, Dip3 = 4, Dip4 = 8, Dip5 = 16, Dip6 = 32, so the game number is 0 to 63.

Which game has which number depends on the roms on the SD card (chapter 9). The game number also selects the emulated soundboard (chapter 6.1), so keep the arrangement of my SD card image (Appendix A).

4.2. Options

4.2.1. Option Dip1: Freeplay

With Dip1 'ON' GottFA80S reads the free play version of the selected game from the SD card - slot 'game number + 64' (chapter 9.2). My SD card images ending in '_FP' contain these free play versions.

In addition 'press and hold' of the credit button simulates a coin in the left coin chute while the game is running.

Switching Dip1 also saves the nvram. The normal and the free play version of a game share the same nvram.

4.2.2. Option Dip2: Init nvram

With Dip2 'ON' GottFA80S initializes the nvram of the selected game to zero during boot. This is useful if you want to reset ALL ram content (recommended for the first start of a game). Set it back to OFF afterwards, otherwise all settings and high scores are cleared at every power on.

4.2.3. Option Dip3: Slam contact open

With Dip3 'ON' the slam contact is simulated as 'open', independent of the real contact. The late System80B games need this. Dip3 has priority over Dip4.

4.2.4. Option Dip4: Slam contact closed

Most System80 games need the slam contact to be closed and will not boot in case the slam contact is open. With Dip4 'ON' the slam is simulated as 'closed', independent of the real contact.

With Dip3 and Dip4 both OFF the real slam contact of the machine is used.

4.2.5. Option Dip5 and Dip6

Not used. They are shown on the boot display (chapter 5.2) but have no function.

4.3. Soundboard options

The four switches of the bank 'soundboard options' replace the DIP switches of the original soundboard. Their meaning depends on the soundboard that is emulated for the selected game (chapter 6.1):

Soundboard option MA-216 and MA-309 games MA-55 and MA-490 games
Dip1 DIP1 and DIP3 of the original soundboard DIP1 'sound or tones' of the original soundboard; many games need it OFF
Dip2 DIP4 of the original soundboard attract sounds on/off (S2 of the original soundboard)
Dip3 DIP5 of the original soundboard -
Dip4 DIP6 of the original soundboard -

For the meaning of the original soundboard DIPs look into the Gottlieb manual of your game. On Mars, Volcano and Black Hole Dip1 and Dip2 also set the interval of the attract sounds (chapter 6.4).

4.4. Gottlieb DIP banks

The four banks S1...S32 are the same as on the original MPU. Consult the manual of your pinball to see how they affect the game behavior.

4.5. Test button and LEDs

The 'test' button (top left) is the sound test of the integrated soundboard (chapter 6.2).

LED Meaning
ON lit as soon as the FPGA program runs
Int lit while the game program is running (regular interrupts)
SD card error while reading the game roms, see chapter 5.1

5. Boot sequence

5.1. Phase 1: loading the game roms

Immediately after switching on, GottFA80S reads the game roms of the selected game from the SD card. Only the modified HW 1.1 (545) reads them from the FPGA flash if no SD card answers (chapter 10).

If reading fails, the 'SD card' LED shows what went wrong, player 4 shows 0000000 and the game does not start:

SD card LED Meaning
blinks 3 times (1 s on, 1 s off), then stays on the card does not answer at all (no card, card not inserted properly)
blinks 4 times, then stays on the card does not answer the SDHC check - very old or unsuitable card
blinks 6 times, then stays on the card does not finish its initialisation
blinks fast, pause, again and again only 545, game roms from the flash: the slot of the selected game is empty (chapter 10)

5.2. Phase 2: info display

Until the game program takes over, the displays show:

Display Content
Player 1 version of the FPGA program running, for example 535 - the first two digits tell you the board (chapter 8.4)
Player 2 game number with three digits, for example 014. With option Dip1 'freeplay' ON 64 is added (078).
Player 3 050963 - lisy.dev identifier for FPGA based MPUs
Player 4 two numbers: the options and the soundboard options, for example 08 03. Options: Dip1 = 1, Dip2 = 2, Dip3 = 4, Dip4 = 8, Dip5 = 16, Dip6 = 32. Soundboard options: Dip1 = 1, Dip2 = 2, Dip3 = 4, Dip4 = 8. 0000000 means the game roms could not be read (chapter 5.1).

5.3. Boot display of System80B games

System80B games (game number 40 to 61) have alphanumeric displays. On these GottFA80S shows a text boot display:

Row Content
1 GOTTFA80S V535 - name and version
2 GAME 040 OPT08 SB03 - game number, options and soundboard options as in chapter 5.2
2, roms from the flash (545) GAME 040 FLASH ROM
2, no SD card GAME 040 NO SD CARD
2, other SD card error SD E3 ... - blink code and the answer of the card, for support
2, slot in the flash empty (545) FLASH ERR GAME 040

5.4. Phase 3: program execution

The game program is started. If it runs (regular interrupts are seen), the 'Int' LED goes ON and the game takes over the displays.

6. Integrated soundboard

GottFA80S comes with an integrated soundboard (GOSOF80) which emulates all Gottlieb System80/80A soundboards and the soundboard of the 'early' System80B games.

6.1. Supported soundboards

The emulated soundboard follows the game number (Appendix A), there is no switch for it.

MA-55 (game numbers 0-9, 11, 13, 15, 17, 19): Panthera - Spiderman - Circus - Counterforce - Star Race - James Bond - Time Line - Force II - Pink Panther - Eclipse, and the 'sound only' (export) versions of Mars, Volcano, Black Hole and Devil's Dare

MA-216 with speech (10, 12, 14, 18, 20, 23, 25, 38, 39): Mars - Volcano - Black Hole - Devil's Dare - Rocky - Striker - Q*Bert's Quest - Caveman

MA-309 (16, 21, 22, 24, 26-29): Haunted House - Spirit - Punk! - Krull - Super Orbit - Royal Flush Deluxe - Goin' Nuts - Amazon Hunt

MA-490 (30-37, 40-42): System80A: Rack 'Em Up - Ready...Aim...Fire! - Jacks to Open - Touchdown - Alien Star - The Games - El Dorado City of Gold - Ice Fever; System80B: Bounty Hunter - Chicago Cubs Triple Play - Tag Team

Game numbers 43 to 63 (the later System80B games) are not emulated by the integrated soundboard.

6.2. Test button

Pressing the 'test' button plays sound #3 of the integrated soundboard ('Tilt tilt tilt' with speech on the MA-216 games, 'oohhhhh' with the others).

6.3. DFPlayer Mini for speech

The integrated soundboard uses a small MP3 player (DFPlayer Mini) for the speech of the MA-216 games. The speech files are stored on a standard micro SD card in the DFPlayer.

You only need the DFPlayer Mini if you want to play a game with speech: Mars - Volcano - Black Hole - Devil's Dare - Rocky - Striker - Q*Bert's Quest - Caveman.

I provide a ZIP file with all speech files on my website. Extract it and copy the content to a micro SD card. Every game has its own folder, named after its game number:

Folder Game
10 Mars
12 Volcano
14 Black Hole
18 Devil's Dare
20 Rocky
23 Striker
25 Q*Bert's Quest
63 Caveman
64 Test (numbers as wav)

6.4. Attract sounds

Mars, Volcano and Black Hole play attract sounds from the DFPlayer while nobody plays. The interval is set with the soundboard options:

Dip1 Dip2 Attract sound
ON OFF every 10 seconds
OFF ON every 2 minutes
ON ON every 4 minutes
OFF OFF off

7. Put the GottFA80 image to the SD card

GottFA80S uses the same SD card image as GottFA80_PLuS. On lisy.dev you find the latest version as a (zipped) image file, with my arrangement of the games (Appendix A). The images ending in '_FP' contain the free play versions as well (chapter 9.2), the images ending in '_Blank' are empty and are meant for your own roms (chapter 9).

After unpacking, write the image to a SD card. I recommend Win32DiskImager for that, see put the image to the SD card:

  • Insert the SD card into your SD card reader and note the drive letter assigned to it, for example E:
  • Download the Win32DiskImager utility from the Sourceforge Project page and install it.
  • Run Win32DiskImager, select the GottFA80 image file and, in the device box, the drive letter of the SD card. Be careful to select the correct drive: if you choose the wrong drive you could destroy the data on your computer's hard disk!
  • Click 'Write' and wait for the write to complete, then eject the SD card.

8. Programming the FPGA

To program the FPGA you need the Quartus Programmer and an USB Blaster.

8.1. Programmer software

It can be downloaded from the Intel website for free, you just need to create a user account. In the download section of Quartus Prime Lite Edition (version 22.1 or later) go to 'Additional Software' and download Quartus Prime Programmer and Tools.

The old Quartus II 13.0sp1 does not know the Cyclone 10 LP; use a current programmer.

8.2. Install the driver for your USB Blaster

When connecting your USB Blaster the first time it will not be recognized correctly by Windows.

You need to install the driver for your USB Blaster. The driver comes together with the installation of the programmer and is located in its 'drivers' subdirectory.

  • Right click on the entry in the device manager and choose 'update driver'
  • Choose 'search for driver on this PC'
  • Select the 'drivers' folder of your programmer installation
  • Confirm installation
  • Now the Altera USB Blaster should be visible under 'USB-Controller'

8.3. Program your FPGA

  1. Connect the USB Blaster to the PC

  2. Start the programmer, make sure in the Hardware setup 'USB-Blaster' is visible and set the Mode to 'JTAG'

  3. Select 'Add File' and choose the right 'jic' file for your board (chapter 8.4). Select the 'Program/Configure' and 'Verify' options.

  4. Power the board, then connect the USB Blaster to the JTAG connector of the FPGA board. Push start and wait for progress 100%. That's it!

The screenshots show an older version of the programmer and another FA board; the current one looks almost the same.

8.4. Board variants and release files

9. Structure of SD card

Due to limitations of the SD card read routine in the FPGA (it reads fixed sector numbers instead of looking for filenames) it is necessary to use my SD card image (about 120 MByte). You can write the image to a SD card of your choice, any size equal to or bigger than 128 MByte will work. The card has to be a SDHC card (that is what you get today with 4 GByte and more).

Note: 'Sandisk' SD cards can not be used with GottFA80S!

9.1. Rom file structure

For each game GottFA80S reads a 16 KByte block from the SD card. Every block starts at sector 660 + slot number x 32 and has this layout:

Offset Size Content
0x0000 2 KByte game rom, e.g. '668-4.cpu'
0x0800 2 KByte second game rom - only the late System80B games (4 KByte game rom), otherwise fill
0x1000 4 KByte sound roms of the integrated soundboard (chapter 6.1), otherwise fill
0x2000 8 KByte system rom, e.g. 'u2_80.bin' + 'u3_80.bin'

The gaps have to be filled, so that every block has exactly 16 KByte. There is no checksum.

How the sound roms fill their 4 KByte depends on the soundboard:

Soundboard Sound part (4 KByte)
MA-216, MA-309 'xxx-s1.snd' + 'xxx-s2.snd' (2 KByte each)
MA-55 'xxx.snd' (1 KByte) + 1K + '6530sy80.bin' (1 KByte) + 1K
MA-490 'xxx-s.snd' (2 KByte) + 2K
none (games 43 to 63) 4K of fill

9.2. Game selection and free play

The first rom file you copy onto the empty ('_Blank') SD card image will be selected with game select '0' (all OFF), the second with '1' (all OFF except Dip1) and so on.

As the FPGA just reads fixed sector numbers the filename is not relevant, you can choose whatever filename you want. It just needs to be placed at the right position on the SD card. You 'select' the position of the rom file on the SD card with the order of your file copy. Make sure each file has exactly 16 KByte.

With option Dip1 'freeplay' ON GottFA80S reads slot 'game number + 64'. So the free play versions follow behind the 64 normal games, in the same order: slot 64 is the free play version of game 0, slot 78 that of game 14 and so on.

Remember that the game number also selects the emulated soundboard (chapter 6.1). If you rearrange the games, a game can end up with the wrong soundboard.

9.3. Examples

The files '1K' ... '7K' do not contain any data and just exist to fill the gaps. They can be downloaded from my software repository on lisy.dev. All commands are for a windows command prompt.

Black Hole (game 14, MA-216 with speech):

copy /b 668-4.cpu + 2K + 668-s1.snd + 668-s2.snd + u2_80.bin + u3_80.bin blckhole

Q*Bert's Quest (game 25, MA-216 with speech, System80A):

copy /b 677.cpu + 2K + 677-s1.snd + 677-s2.snd + u2_80a.bin + u3_80a.bin qbquest

Panthera (game 0, MA-55):

copy /b 652.cpu + 2K + 652.snd + 1K + 6530sy80.bin + 1K + u2_80.bin + u3_80.bin panthera

Rack 'Em Up (game 30, MA-490):

copy /b 685.cpu + 2K + 685-s.snd + 2K + u2_80a.bin + u3_80a.bin rackemup

Bounty Hunter (game 40, System80B, MA-490) - one 8 KByte rom, no separate game rom:

copy /b 2K + 2K + 694-s.snd + 2K + bountyh.cpu bountyh

Raven (game 44, System80B, no emulated soundboard):

copy /b raven2.cpu + 6K + raven1.cpu raven

Bad Girls (game 57, late System80B with a 4 KByte game rom):

copy /b badgirls2.cpu + 4K + badgirls1.cpu badgirls

10. Game roms in the FPGA flash (HW 1.1 modified)

New with software x.x5, only with the FPGA program 545. The FPGA boots from a flash chip (EPCS16, 2 MByte) on the FPGA board, and the space behind the FPGA program can hold the game roms of all 64 games and their free play versions. A board with roms in the flash runs without SD card.

On the normal GottFA80S boards the chip select of the SD card sits on the FPGA pin next to the flash clock, so the FPGA cannot read its own flash there. The modified HW 1.1 moves the SD card chip select: a wire bridge on the FPGA board from pin 11 to pin 42. Only with this bridge, program 545.

  • With a card in the slot the card always wins. So you can still try other roms from a card without touching the flash.
  • If the card is missing or does not answer, the board reads the flash. The SD card LED does not light then.
  • There is no checksum. GottFA80S only checks that the slot of the selected game is not empty; an empty slot shows the flash blink code (chapter 5.1).

The roms are copyrighted, so they cannot be part of the download from lisy.dev. You put them there yourself, from your own SD card image:

  1. Build the rom file. In the GottFA80 source tree (github.com/bontango/GottFA80) run

     scripts\make_flash_hex.ps1 -Image <image file> -Out variants\80s_hw10_cyclone_iv\output_files\gottfa80_roms.hex -Verify

    The script takes every slot that contains a game. Identical 2 KByte parts (the system roms, the fill) are stored only once, so all 128 slots of my image fit.

  2. Build the FPGA program in the folder variants\80s_hw10_cyclone_iv and run quartus_cpf -c gottfa80_roms.cof there. This puts the FPGA program and the roms into one file, output_files\gottfa80_roms.jic.

  3. Program gottfa80_roms.jic with the Quartus Programmer instead of the normal file, with 'Verify' ticked (chapter 8.3).

Keep that file to yourself. It contains the game roms and must not be passed on.
